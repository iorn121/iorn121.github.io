Rhythm Mile（リズムマイル）

概要

ランニングと BPM に基づいた音楽プレイリストを組み合わせたモバイルアプリです。ランナーのペースに合わせて最適な音楽を提供し、より楽しく効果的な運動体験を目指しています。

  • ランニング: GPS による距離・ペース・ルート記録、履歴と目標設定
  • ルート: 目標距離や勾配を考慮したルート提案（予定）
  • 音楽: BPM とペースに連動したプレイリスト（予定）

フェーズ 1 は Android（Material Design 3）を優先。将来 iOS と PWA への展開を想定しています。
