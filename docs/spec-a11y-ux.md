# 仕様: トップページの a11y / UX 改善

## 背景

GitHub Issue #3 で、動きを抑える設定、見出しサイズ、キーボード操作、コルク背景上の文字コントラストに改善点が挙げられている。

## スコープ

- `prefers-reduced-motion: reduce` の利用者には、ポラロイドカードの傾きとホバー時の移動を適用しない。
- `.title` の `pt` 指定を、ルート文字サイズに追従する `rem` ベースの `clamp()` に置き換える。
- 共通ヘッダーに「メインコンテンツへ」スキップリンクを追加し、`#app` をフォーカス可能にする。
- コルク背景上の基本文字色を濃色にし、タイトル、フィルター、フッターには十分なコントラストを保つ背景を付ける。

## 非スコープ

- レイアウトやコンテンツの再設計
- 新規依存関係の追加
- プロジェクトデータや記事本文の変更

## 影響ファイル

- `src/main.ts`
- `src/ui/site-header.ts`
- `css/style.css`

## 検証

```bash
npm run lint
npm run build
```

加えて、通常設定と `prefers-reduced-motion: reduce` の両方でトップページを表示し、スキップリンクのフォーカス移動とカード表示を確認する。
